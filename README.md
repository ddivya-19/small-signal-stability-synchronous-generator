# Small-Signal Stability Analysis of Synchronous Generator
This project is about studying how a synchronous generator behaves when it experiences a small disturbance.
I developed a nonlinear third-order model in Python and simulated the generator response. The model is linearized around its operating point, and eigenvalue analysis is used to determine the small-signal stability of the system.
### Work Done
- Developed the synchronous generator model
- Calculated the equilibrium operating point
- Linearized the nonlinear model
- Calculated and analyzed system eigenvalues
- Simulated rotor-angle response after a small disturbance
- Studied damping and oscillations
- Performed damping sensitivity analysis
### Result
The rotor angle shows damped oscillations after the disturbance, showing that the system returns toward its operating condition.
